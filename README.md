# SQL Practice Repository

## About This Repository

This repository contains SQL practice files created to learn and practice fundamental SQL concepts. It includes SQL scripts for creating tables, inserting data, writing basic queries, using aggregate functions, and performing joins.

The purpose of this repository is to build a strong foundation in SQL and develop practical skills in querying and working with relational databases.

## Topics Covered

### 1. Creating Tables

File: `create table.sql`

Practice creating database tables and defining their columns and data types.

### 2. Inserting Data

File: `insert_data.sql`

Practice inserting records into database tables using SQL `INSERT` statements.

### 3. Basic SQL Queries

File: `basic queries.sql`

Practice writing basic SQL queries to retrieve and work with data.

### 4. Aggregate Functions

File: `aggregate fun.sql`

Practice using SQL aggregate functions to perform calculations on data.

Common aggregate functions include:

* `COUNT()` – Counts rows or values.
* `SUM()` – Calculates the total of numeric values.
* `AVG()` – Calculates the average.
* `MAX()` – Returns the maximum value.
* `MIN()` – Returns the minimum value.

### 5. SQL Joins

File: `joins.sql`

Practice combining data from multiple tables using SQL joins.

## Tools and Technologies

* **Language:** SQL
* **Database Tool:** MySQL Workbench
* **Database Type:** Relational Database

## How to Use

1. Clone or download this repository.
2. Open MySQL Workbench or another compatible SQL environment.
3. Connect to your database server.
4. Open the required `.sql` file.
5. Review the SQL statements and execute them in the appropriate order.
6. Check the output to understand how each query works.

**Note:** The scripts may need to be executed in the correct order depending on their table definitions and dependencies.

## Learning Objectives

* Understand basic SQL syntax.
* Learn how to create tables and insert records.
* Retrieve data using SQL queries.
* Perform calculations using aggregate functions.
* Understand how to combine data from multiple tables.
* Develop practical database querying skills.
